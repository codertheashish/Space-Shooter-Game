# 🚀 Space Shooter – Final Version 

### Fast Gameplay • Bigger Bullets • Auto Speed Increase • 5 Lives System

A polished **Space Shooter game** built using **Python + Pygame**, featuring smooth movement, large bullets, dynamic enemy waves, a starry animated background, and a clean Game Over screen with Restart/Exit options.

Each shot increases the score, enemies disappear when hit, and the player survives with **5 lives** before Game Over. Enemy speed slowly increases over time, making the game progressively harder.

---

## ✨ Game Features

### 🔫 Shooting System

* Fire bullets using **SPACE**
* Bullets are **bigger and easier to hit**
* Score increases **every time you shoot**

### 👾 Enemy System

* 6 enemies spawn from the top
* Auto-respawn after being destroyed or leaving the screen
* Enemy speed **gradually increases** to boost difficulty
* Enemy disappears instantly when hit

### ❤️ Lives System

* Player has **5 lives**
* Collision with any enemy reduces life
* Game ends when lives reach zero

### 🌌 Stars Background

* Dynamic star generation for a smooth space feel

### 🎮 Controls

* **Left / A** → Move Left
* **Right / D** → Move Right
* **SPACE** → Shoot
* **R** → Restart (Game Over screen)
* **ESC** → Exit anytime

### 🖥 Game Over Screen

* Shows final score
* Options to Restart or Exit
* Clean colored UI text

## ▶ How the Game Works

* Player ship moves left/right at the bottom
* Press SPACE to fire bullets
* Every shot = +1 score
* Bullets destroy enemies on impact
* Enemies fall from the top with slowly increasing speed
* Touching an enemy causes **life loss**
* After 5 collisions → **Game Over**
* Restart anytime using **R**
